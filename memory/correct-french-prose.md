When project's code comments, plan files and `sumup.md` are written in French.
That French must be grammatically and semantically correct: real words used
with their real meanings, correct agreement, correct prepositions, standard
French typography (space before `: ; ? !`, `«  »` for quotes).

**Why:** the user is a native French speaker and reads this prose as the
project's documentation. Wording that is merely plausible, or metaphor bent to
fit, reads as wrong to them.

**How to apply:** write plain declarative French; describe what the code does
rather than reaching for an image. If unsure a phrase is idiomatic, use a
simpler construction that is certainly correct. See [[plain-professional-tone]].
